# 여행 번역 카메라 (안드로이드)

일본 여행용 카메라 번역 앱이에요.

- **실시간 카메라 번역**: 일본어에 카메라를 비추면 한국어가 글자 자리에 바로 겹쳐 보여요.
- **사진 번역**: [촬영]을 누르면 화면을 멈추고 번역해요. 목록을 누르면 일본어 발음을 들려주고, [저장]을 누르면 번역이 붙은 사진을 사진첩(Pictures/TabiCamera)에 저장해요. [앨범]으로 이미 찍은 사진도 번역할 수 있어요.
- **음성 통역 (듣기 / 말하기)**:
  - [한국어로 말하기]: 말하는 동안 일본어 번역이 실시간으로 보이고, 말을 마치면 일본어 음성으로 읽어 줘요.
  - [일본어 듣기]: 상대방의 일본어를 실시간으로 한국어로 보여줘요.
  - **통역 모드**를 켜면 내 말이 일본어로 나온 뒤 자동으로 상대방의 대답을 듣는 식으로 대화가 이어져요.
  - 말풍선을 누르면 다시 읽어 주고, 길게 누르면 크게 보여줘요.
  - 인터넷 없이 음성 인식을 쓰려면 휴대폰에 **오프라인 음성 인식 언어 팩**이 있어야 해요. 갤럭시 기준 설정 > 일반 > 음성 입력(또는 Google 음성 입력) > 오프라인 음성 인식에서 한국어와 일본어를 받아 두세요.
- **오사카 길 (오프라인)**:
  - 지하철 경로: 오사카 메트로 8개 노선, JR 순환선·유메사키선(USJ), 공항 가는 하루카·난카이 노선에서 출발역·도착역을 고르면 환승·방면·정거장 수·대략 시간을 인터넷 없이 보여줘요.
  - 명소 길안내: 29곳의 명소를 고르면 GPS와 나침반으로 방향 화살표와 거리를 보여줘요. 구글맵 도보·대중교통 길찾기로 바로 넘어갈 수도 있어요(인터넷 필요).
  - 내 장소: 숙소 좌표를 저장해 두면 데이터가 없어도 돌아올 수 있어요.
- **여행 도구 (오프라인)**: 회화 50문장(발음 포함), 한자 사전, 환율·면세 계산, 알레르기 카드, 택시 주소 카드, 긴급 연락처가 들어 있어요.
- **오프라인 동작**: 글자 인식과 번역 모두 기기 안에서 해요. 처음 실행할 때 번역 모델(약 60MB)만 한 번 받으면 이후에는 인터넷 없이 써요. **출국 전에 Wi-Fi에서 꼭 한 번 실행하세요.**

## APK 만드는 방법

### 방법 A: GitHub에서 자동으로 만들기 (Android Studio 설치 필요 없음, PC 브라우저 필요)

1. github.com에 가입하고 로그인해요.
2. 오른쪽 위 **+** 메뉴에서 **New repository**를 누르고, 이름을 `TabiCamera`로 정한 뒤 **Create repository**를 눌러요.
3. 생성된 저장소 화면에서 **uploading an existing file**을 눌러요. 압축을 푼 `TabiCamera` 폴더 **안의 모든 파일과 폴더**를 끌어다 놓아요. `.github` 폴더도 꼭 함께 올려야 해요. 그다음 **Commit changes**를 눌러요.
4. 저장소의 **Actions** 탭에서 **Build APK**가 초록색 체크로 끝날 때까지 기다려요 (약 5~10분).
5. 완료된 실행을 열고 아래쪽 **Artifacts**에서 `TabiCamera-apk`를 내려받아요. 받은 zip 파일 안에 `app-debug.apk`가 있어요.

### 방법 B: Android Studio

Android Studio에서 **Open**으로 이 폴더를 열어요. 동기화가 끝나면 메뉴에서 **Build > Build App Bundle(s) / APK(s) > Build APK(s)**를 눌러요.
APK는 `app/build/outputs/apk/debug/app-debug.apk`에 만들어져요.

## 휴대폰에 설치하기

1. 휴대폰으로 `app-debug.apk`를 옮겨요 (카카오톡 나에게 보내기, 구글 드라이브, USB 등).
2. 파일을 눌러 설치해요. "출처를 알 수 없는 앱" 경고가 나오면 **설정에서 이 출처 허용**을 켜요.
3. 앱을 처음 열면 카메라 권한을 허용하고, Wi-Fi에서 번역 모델을 받아요.

- 지원 기기: Android 8.0 이상 (사진 저장은 Android 10 이상)
- 일본어 발음 듣기가 안 되면: 설정 > 일반 > 텍스트 음성 변환에서 일본어 음성을 설치해요.
- 번역은 기계 번역이라 메뉴 이름이 어색하게 나올 수 있어요. 알레르기나 약 정보는 직원이나 약사에게 꼭 다시 확인하세요.
